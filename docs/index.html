EASY SETUP GUIDE

খুব সহজে যেভাবে সেটআপ করবেন

মাত্র ৩০ সেকেন্ডে যেকোনো ওএসে চালু করার নিয়মাবলী:

🍏

macOS এ যেভাবে চালাবেন

  1. ShotgunKeys-macOS.zip ডাউনলোড করে আনজিপ করুন।
  2. ShotgunKeys.app টিকে Applications ফোল্ডারে নিয়ে ডাবল ক্লিক করুন।
  3. মেনু বারের 🔥 আইকনে ক্লিক করে "Grant Permission" দিয়ে Accessibility পারমিশন অন করুন।
🪟

Windows এ যেভাবে চালাবেন

  1. ShotgunKeys-Windows.zip ডাউনলোড করে এক্সট্রাক্ট করুন।
  2. ফোল্ডারে থাকা run.bat ফাইলে ডাবল ক্লিক করুন।
  3. অ্যাপ্লিকেশনটি ওপেন হবে এবং সিস্টেম ট্রে-তে মিনিমাইজ হয়ে ব্যাকগ্রাউন্ডে চলবে!
🤖

Android এ যেভাবে চালাবেন

  1. ShotgunKeys.apk ফাইলটি ডাউনলোড করে ফোনে ইনস্টল করুন।
  2. অ্যাপটি ওপেন করে "Enable Accessibility" বাটনে ট্যাপ করে পারমিশন অন করুন।
  3. এখন যেকোনো কীবোর্ডে (GBoard, WhatsApp, ইত্যাদি) টাইপ করলেই শর্টগান সাউন্ড বাজবে!
