=====================================================
         SHOTGUNKEYS - CUSTOM SOUNDS FOLDER
=====================================================

Drop your own audio files (.wav, .mp3, .ogg, .flac) here to use the "Custom (User Folder)" preset!

FILE NAMING CONVENTIONS:
------------------------
1. Key Blast Sounds:
   Include "blast", "shot", "fire", or "gun" in the filename.
   Examples:
     - blast1.wav
     - shotgun_shot.mp3
     - heavy_blast.wav
     - fire_01.ogg

2. Reload Sounds (Space / Enter):
   Include "reload", "pump", "cock", or "action" in the filename.
   Examples:
     - reload1.wav
     - pump_action.mp3
     - heavy_reload.wav
     - cock_01.ogg

HOW IT WORKS:
-------------
- When "Custom (User Folder)" profile is selected, ShotgunKeys automatically scans this folder.
- If multiple blast or reload files are added, ShotgunKeys will randomly alternate between them with micro pitch dynamics.
- If no matching sounds are found, it gracefully falls back to the Realistic 12-Gauge sounds.
- To refresh sounds after adding or removing files, click "Reload Audio" in the ShotgunKeys app or Tray Menu.

Enjoy your custom sound effects!
